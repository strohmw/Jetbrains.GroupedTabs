# GroupedTabs

<!-- Plugin description -->
GroupedTabs lists the open editors of the current Rider solution in a tool window named Tabs. Files are grouped by project, with a separate group for files that sit outside the solution, including compare editors opened from Commit.

**Open files**

- Select a row to focus that editor. Middle-click, or the close button, closes it.
- Unsaved files stay green, including the file that is selected.
- Pin a file so it stays in a pinned section. Pin and unpin from the row button, the right-click menu, or, when enabled, a double-click.
- Drag a row out of the window to detach it. The menu can also detach the file or split the editor vertically or horizontally.
- Right-click a file for close, pin, local history, Git, locate in Solution Explorer, copy path, and open in the file explorer.
- Right-click a project header to close every tab in that project.
- Right-click empty space to close every tab, close unpinned tabs, or refresh the list.
- Compare editors opened from Commit appear under Outside the project and can be closed from the list.

**Appearance**

- Each project keeps its own colour stripe. Stripes avoid colours already used by other open projects, and a colour chosen with Set Tab Color stays.
- Groups can be folded. An optional folder tree shows files under their directories.
- Project and module headers have their own case, font, size, text colour, and background. File names have their own case and size.

**Settings**

Settings live under Settings, Tools, GroupedTabs.

- Place the tool window on the left or the right.
- Sort by module and path, name, project and name, or last modified.
- Hide the native editor tabs. Turning this off restores the placement Rider was using before.
- Group by module, show the full path as the label, sort project groups by path, and show a file-type icon.
- Show or hide the pin button, the close button, and bold text on the selected file.
- Show a stable colour stripe, and turn double-click pin on or off.
- Reset all styles restores the header and file-name styles. The window options stay as they are until you apply them.
